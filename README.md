# bright-parser-tool

ML engineer · R and tidyverse

拿来练手的小仓库

## 用法

```bash
cat data.txt | go run main.go
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/bright-parser-tool.git
cd bright-parser-tool
go build ./...
```
